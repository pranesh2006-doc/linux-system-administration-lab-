| Command      | Purpose                     |
| ------------ | --------------------------- |
| `df -h`      | Check filesystem disk space |
| `du -sh ~`   | Check home directory size   |
| `du -sh ~/*` | Find directory/file sizes   |
| `lsblk`      | Show disks and partitions   |
| `lsblk -f`   | Show filesystem details     |
| `mount`      | Show mounted filesystems    |
| `umount`     | Unmount a filesystem        |
